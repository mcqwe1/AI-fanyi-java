# AI 视频翻译 · 使用手册

本手册覆盖软件全部功能的使用方法。智能客服的回答依据就是这份文档。

## 软件是什么

AI 视频翻译是一个本地运行的视频/音频/文本翻译工作台：上传视频或音频，自动完成语音识别、字幕清洗、AI 翻译，产出 SRT 字幕、译文 TXT，还能把字幕烧录进视频、生成 AI 配音。所有数据都存在你自己电脑上，服务只监听本机（localhost），不会上传到任何服务器。

## 快速上手（三分钟）

1. 双击 `start.bat` 启动（首次约 20 秒），浏览器自动打开 http://localhost:8080
2. 用 demo / demo123 登录，或注册自己的账号
3. 首次登录会弹出配置向导：填好两把钥匙——语音识别（Groq Key，或选本地 Whisper 免钥匙）和 AI 翻译模型（任何 OpenAI 兼容接口，推荐 DeepSeek）
4. 回首页选一个模式（普通视频翻译最常用），上传文件，选目标语言，点「开始翻译」
5. 进度条走完后：下载 SRT 字幕 / 译文 TXT / 编辑字幕 / 烧录 / 配音
6. 用完双击 `stop.bat` 关闭

## 启动、端口与数据目录

- `start.bat`：一键启动；被 Windows SmartScreen 拦截时点「更多信息 → 仍要运行」；杀毒误报请加白名单
- 端口被占用：用 `start.bat 9090` 换端口启动，然后浏览器访问 localhost:9090
- `stop.bat`：关闭全部服务
- `data\` 文件夹：全部用户数据（数据库、上传的视频、生成的字幕、API 密钥）。备份或搬家只需拷走这个文件夹
- `data\backend-8080.log`：后端日志，出问题先看它
- `app\`、`runtime\`、`bin\`、`ai-service\`：程序本体、内置 JRE、内置 FFmpeg、内置 Python 与 Whisper 模型，不要动

## API 密钥配置（设置 → API 密钥）

**AI 翻译模型（必填）**：负责把字幕翻译成目标语言。支持任何 OpenAI 兼容接口。推荐 DeepSeek：
1. 打开 platform.deepseek.com，手机号注册并充值少量金额
2. 在「API Keys」页创建 key（sk- 开头）
3. 填入设置：Base URL 填 `https://api.deepseek.com`，API Key 填 sk- 开头的钥匙，模型填 `deepseek-v4`
也可以用通义、智谱、各类中转站，换 Base URL 和模型名即可。

**语音识别（视频/音频翻译需要，四选一）**：
- Groq（免费，需要代理/魔法上网）：打开 console.groq.com/keys 注册，创建 API Key（gsk_ 开头），填到「Groq API Key」。注意免费层一次只能处理约 2 小时以内的音视频
- Groq Turbo：同一把 Groq 钥匙，速度更快，精度略低
- 本地 Whisper（完全离线、免钥匙）：完整版内置 base/small/medium/large-v3 四个模型，任务页直接选「本地 xxx」即可；有 NVIDIA 显卡自动 GPU 加速，没有则用 CPU（会慢一些）。无法访问 Groq 时用它
- 阿里 DashScope Key / 智谱 Key：对应的国产语音识别，能直连不需要代理

**Gemini（术语库模式需要）**：术语库AI视频翻译用 Gemini 联网抽取术语，需在设置里填 Gemini 的 Base URL、API Key 和模型。

## 五种翻译模式怎么选

- **普通AI视频翻译**：最常用。上传视频，转写+翻译，出字幕。不需要术语积累时用它
- **音频AI翻译**：和普通模式一样，只是上传的是音频文件（mp3/wav/m4a 等）
- **术语库AI视频翻译**：翻译系列视频（同一部剧、同一个主播）时用。术语挂在「系列项目」上，一系列共用、越攒越准，保证人名地名前后一致
- **全能AI翻译（实验）**：最智能的模式。多个领域专家自动判断内容领域、抽术语、可联网核实译法，再带着术语表翻译。视频、音频、纯文本都能收
- **文本AI翻译**：纯文本快速翻译，不走术语流程

## 普通AI视频翻译 / 音频AI翻译

1. 左侧栏进「普通AI视频翻译」（或「音频AI翻译」）
2. 上传视频（mp4/mkv/mov 等）或音频（mp3/wav/m4a 等）
3. 选语音识别引擎（Groq / Groq Turbo / 本地 Whisper 各档）
4. 选源语言（可自动检测）和目标语言，需要的话勾「双语字幕」
5. 可开「翻译风格」：选预设或自己写一句风格要求
6. 点「开始翻译」。进度：抽音频 → 语音识别 → 翻译 → 完成
7. 完成后可以：编辑字幕、下载 SRT、下载译文 TXT、字幕烧录、AI 配音
8. 对结果不满意点「重试」：可以换识别引擎或语言重跑，不用重新上传文件

## 术语库AI视频翻译（KB 模式）

适合翻译系列内容：术语表挂在「系列项目」上，同一系列的视频共用一份术语，越翻越准。

1. 进「术语库AI视频翻译」，先新建或选择一个系列项目
2. 上传视频，开始任务。流程会多一步「构建术语库」：AI 通读转写全文，按六大类（人名/地名/机构品牌/作品名/文化专有项/科技专名）抽出术语并联网核实译法
3. 抽出的术语自动入库（已有的、人工改过的不会被覆盖）
4. 随时可以人工审核：在 KB 页内联表格或「术语库」管理页修改译法、启用/停用、增删
5. 翻译时自动注入该系列已启用的术语，保证全片一致
需要在设置里配好 Gemini（抽术语用）。

## 全能AI翻译（Agent 模式，实验功能）

上传后系统自动运转：识别内容领域 → 派多个领域专家并行抽术语 → 需要时联网核实译法 → 汇总仲裁打分 → 术语入库 → 带术语翻译全文。视频、音频、纯文本（txt/md/srt/vtt）都能处理。

**运行现场**：提交后右侧实时展示每一步——识别领域、专家抽词、联网查了什么（带可点开的网页链接）、汇总仲裁、术语入库、翻译。出问题的步骤会标黄色「降级」。

**模型配置（设置 → 全能AI翻译）**：主模型负责判断领域，子模型负责抽词定译。不填就自动用翻译模型。

**联网搜索（强烈建议配置）**：配了搜索引擎（Tavily / 博查 / Serper 三选一，填对应 API Key），专家遇到拿不准的专名会去搜官方译名，搜到权威来源的词直接高分入库。不配也能跑，但术语只能靠模型自身知识。Tavily 在 tavily.com 注册可拿免费额度；博查是国内服务可直连。

**术语可信度四档**：
- 已确认：有权威来源佐证（或多次任务反复验证），直接可信
- 待确认：AI 多方一致但没有外部证据，建议过一眼。同一个词在后续任务里译法保持一致会自动加分，连续两三个视频一致就自动转为「已确认」
- 策略词：没有标准答案的词（音译/造词），入库是为了全片统一
- 本次临时：把握不大，只在本次翻译里用，不进术语库
在「术语库」页人工改过的词会被锁定，之后 AI 永远不会覆盖它。

**我的专家**：可以自建最多 20 个领域专家（比如「机甲动画」「王者荣耀」）。填三样：什么内容归他管（帮系统判断）、这个领域的翻译惯例（怎么译）、搜索关键词（联网核实时带上的词，比如「高达wiki」）。建好后自动进入候选池，内容对得上就会被自动选中，不需要手动指定。

**LangSmith（可选，开发者功能）**：填 LangSmith Key 后，每次任务的完整执行过程（提示词全文、搜索结果、术语表）会上报到 LangSmith 网页端供分析。注意上报内容含完整台词，介意隐私就别开。

## 文本AI翻译

进「文本AI翻译」，粘贴或上传文本，选语言，直接翻译。适合快速翻译一段话、一篇文章，不涉及术语库。

## 字幕编辑器

任务完成后点「编辑字幕」进入编辑器：逐行改译文、调时间轴、合并拆分行，改完可重新导出 SRT。字幕已存在本地数据库，随时能回来接着改。

## 字幕烧录

把字幕直接压进视频画面（硬字幕）。任务完成后点「字幕样式/烧录」，可调字体、字号、颜色、描边、位置，烧录完下载带字幕的视频文件。

## AI 配音（TTS）

任务完成后可为译文生成 AI 配音。默认用 Edge-TTS（免费、零配置、无需钥匙）。进配音页选音色、生成，完成后试听下载。个别行译文过长时会黄色提示（不影响成品）。配音失败不影响翻译成果，可以重试。

## 术语库管理

左侧栏「术语库」页统一管理所有术语：
- 按项目/类别/来源筛选，搜索词条
- 修改译法、说明，启用/停用，批量移动、复制到其他项目，批量删除
- 「来源」列：自动=AI 抽取待审核；人工=你自己录入或改过的（AI 不会覆盖）
- 「说明/依据」列：这个词为什么这么译（策略、理由、出现次数、是否有其他译法争议）
- 全能翻译产出的术语桶名字带【Agent】前缀，按领域自动归类

## 翻译风格

各模式的任务表单里可开「翻译风格」：选预设标签或用一句话描述期望文风（比如「口语化、贴吧味」「正式书面语」）。术语表的优先级高于风格——术语对照永远严格执行。设置页「风格与术语」可设默认风格和自定义术语抽取提示词。

## 我的任务

「我的任务」页看全部任务：进度、状态、失败原因。可以重试（不用重新上传）、删除。任务文件都在本地 `data\` 目录。

## 常见问题（FAQ）

**翻译失败提示密钥错误**：检查 key 是否复制完整、账户是否有余额；Groq 报网络错误多半是代理没开。

**视频翻译有漏句**：软件有多层防漏机制（轻声检测、缺口补翻、漏行补翻）。如果译文里个别行保留了原文，说明那几行翻译请求失败被自动兜底，任务会标「部分步骤降级」，点「重试」通常能补全。耳语/气声内容识别难度大，建议用 Groq 或本地 large-v3 模型。

**全能翻译不联网搜索**：先确认设置里「全能AI翻译」页签配了搜索引擎和对应 API Key；另外是否联网由 AI 判断——内容里没有生僻专名时它认为不需要查证，属正常现象。

**术语全是「待确认」**：没配联网搜索时 AI 拿不到外部证据，最高只能给到待确认档。配上搜索引擎，或者连续翻几个同领域视频（译法一致会自动转正），或者在术语库页手动确认。

**Groq 用不了**：国内网络需要代理才能访问 Groq（注册和使用都是）。不想用代理就选「本地 Whisper」，完全离线。

**处理长视频**：Groq 免费层一次只能处理约 2 小时内的音视频，更长的用本地 Whisper。

**数据备份/搬家**：全部数据在软件目录的 `data\` 文件夹里，拷走它就完成备份。换电脑把整个软件文件夹拷过去即可。

**安全性**：服务只监听本机，外网访问不了；密钥存在本机数据库。不要把 `data\` 文件夹发给别人。

**端口被占用**：`start.bat 9090` 换端口。

## 隐私与数据

所有视频、音频、字幕、术语、密钥都存储在本机 `data\` 目录，软件本身不上传任何数据。会访问外网的只有你主动配置的服务：翻译模型接口、Groq 语音识别、联网搜索引擎、LangSmith 观测（默认全部可用本地方案或关闭）。
