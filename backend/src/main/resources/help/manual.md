# 狐译 · 使用手册

本手册覆盖软件全部功能的使用方法。智能客服的回答依据就是这份文档。

## 软件是什么

狐译是一个本地运行的视频/音频/文本翻译工作台：上传视频或音频，自动完成语音识别、字幕清洗、AI 翻译，产出 SRT 字幕、译文 TXT，还能把字幕烧录进视频、生成 AI 配音。所有数据都存在你自己电脑上，服务只监听本机（localhost），不会上传到任何服务器。

## 快速上手（三分钟）

1. 双击 `start.bat` 启动（首次约 20 秒），浏览器自动打开 http://localhost:8080
2. 用 demo / demo123 登录，或注册自己的账号
3. 首次登录会弹出配置向导：填好两把钥匙——语音识别（Groq Key，或选本地 Whisper 免钥匙）和 AI 翻译模型（推荐 DeepSeek，保存后自动成为默认模型服务）
4. 回首页选一个模式（普通视频翻译最常用），上传文件，选目标语言，点「开始翻译」
5. 进度条走完后：下载 SRT 字幕 / 译文 TXT / 编辑字幕 / 烧录 / 配音
6. 用完双击 `stop.bat` 关闭

## 启动、端口与数据目录

- `start.bat`：一键启动；被 Windows SmartScreen 拦截时点「更多信息 → 仍要运行」；杀毒误报请加白名单
- 端口被占用：用 `start.bat 9090` 换端口启动，然后浏览器访问 localhost:9090
- `stop.bat`：关闭全部服务
- `data\` 文件夹：全部用户数据（数据库、上传的视频、生成的字幕、API 密钥）。备份或搬家只需拷走这个文件夹
- `data\backend-8080.log`：后端日志，出问题先看它
- `app\`、`runtime\`、`bin\`、`ai-service\`：程序本体、内置 JRE、内置 FFmpeg、内置 Python 与 Whisper 模型，不要动

## API 配置（设置 → API 配置）

设置页的「API 配置」按服务类型分三块：大语言模型、语音识别（ASR）、语音合成（TTS）。所有密钥只存本机数据库。

**大语言模型（翻译模型，必配）**：负责把内容翻译成目标语言。服务商下拉支持 DeepSeek、Qwen（通义千问）、Gemini（谷歌）、GPT（OpenAI）、GLM（智谱）、Claude（Anthropic）、Grok（xAI）等大模型，谷歌翻译、微软翻译、DeepL 三家传统机器翻译，以及两种自定义通用格式（OpenAI 格式 / Claude 格式，可接中转站、one-api、ollama 等任何兼容端点）。配置步骤：
1. 选服务商——Base URL 和推荐模型自动填好（表单下方有各家控制台入口和拿 Key 提示）
2. 粘贴 API Key，点「拉取模型」选模型
3. 点「测试连接」——会真实翻译一句话验证配置是否可用
4. 点「保存服务」。第一条服务自动设为默认；可以保存多家服务，在「已配置的模型服务」列表里随时「设为默认」切换、启用/停用、编辑、删除
5. **带「默认」标记且启用的服务，就是所有翻译模式实际使用的模型**

Base URL 会在保存时自动补全 `/v1`（地址里已有 /v4、/v1beta 等版本号则不动）。推荐 DeepSeek：platform.deepseek.com 注册充值，创建 sk- 开头的 Key，模型选 `deepseek-chat`。

**并发请求数**（每条模型服务可单独设，0 = 用默认值 8）：同时向该端点发几路翻译请求。只有长视频和整本文档吃得到并发——实测 1778 行要切成 45 批，8 路约 28 秒、16 路约 15 秒；而 17 分钟以内的视频只有 7 批，一波就跑完，调了也没用。调太高会触发服务商限流，被限流的批次会保留原文（任务会标「部分步骤降级」）。不确定就留 0。

注意：谷歌翻译/微软翻译/DeepL 是传统机器翻译——速度快，但不支持翻译风格和术语提示；全能AI翻译、智能客服等需要大模型的功能不能用它们。微软翻译的「区域」填资源所在区（如 eastasia），全球资源留空。

**语音识别（视频/音频翻译需要）**：在「语音识别（ASR）」面板配置。
- 本地 Whisper（完全离线、免钥匙、零配置）：内置 base/small/medium/large-v3 四个模型，任务页直接选「本地 xxx」即可；有 NVIDIA 显卡自动 GPU 加速，没有则用 CPU（会慢一些）。无法访问 Groq 时用它
- Groq（免费，需要代理/魔法上网）：打开 console.groq.com/keys 注册，创建 API Key（gsk_ 开头）填入保存。注意免费层一次只能处理约 2 小时以内的音视频；Groq Turbo 同一把钥匙，速度更快精度略低
- 用哪个引擎是提交任务时选的，每个任务可以不同

**语音合成（AI 配音需要）**：在「语音合成（TTS）」面板选引擎——Edge-TTS（免费零配置）、硅基流动 CosyVoice2（只填 API Key）、OpenAI 兼容端点（Base/Key/模型全填）。

## 模型管理（设置 → 模型管理）

所有已配置模型的总览页：大语言模型服务列表（可设默认/启停/删除）、全能AI翻译四个角色（翻译模型/主 Agent/子 Agent/搜索引擎）的配置状态、语音识别、语音合成，每行都有「去配置」直达对应设置面板。

## 账号与安全（设置 → 账号与安全）

- **头像**：点「更换头像」选图片，自动裁剪成正方形小图，只存本机；「恢复默认」换回软件 logo
- **修改用户名**：填新用户名（2~32 字符）+ 登录密码验证，改完自动换发登录凭证，无需重新登录
- **修改密码**：原密码 + 新密码（至少 6 位）
- **注销账号**：危险操作区「注销账号」，输密码并勾选确认后账号永久停用、密钥数据清除；翻译任务与文件保留在本机 data 目录。最后一个管理员不能注销——先在管理员后台把其他账号设为管理员

## 帮助中心与反馈

侧边栏「帮助与反馈」会在新标签页打开帮助中心：分类文档、搜索、更新日志一应俱全。右上角「反馈与建议」可提交功能建议或问题反馈（保存在本机，管理员后台可查看）。右下角悬浮球是智能客服，基于本手册回答使用问题。

## 四种翻译模式怎么选

- **音频/视频翻译**：最常用。上传视频（mp4/mkv/mov 等）或音频（mp3/wav/m4a 等），转写+翻译，出字幕。**手头已有原文字幕的话，开「已有字幕」开关可跳过语音识别，快十倍以上**。不需要术语积累时用它（在侧边栏「音视频翻译」分组下）
- **全能AI翻译（实验）**：最智能的模式。多个领域专家自动判断内容领域、抽术语、可联网核实译法，再带着术语表翻译。视频、音频、纯文本都能收（在侧边栏「Agent翻译」分组下）
- **文本AI翻译**：纯文本快速翻译，不走术语流程（在侧边栏「文本翻译」分组下）
- **文档AI翻译**：整份文档上传翻译，保留原格式排版（PDF/Word/ePub/HTML/Markdown/TXT/JSON/字幕文件）
- **划词翻译**：浏览器里随处翻（在侧边栏「插件」分组下），支持划词/输入框/图片/整页，记录进本页自己的翻译历史

## 音频/视频翻译

1. 左侧栏「音视频翻译」分组进「音频/视频翻译」
2. 上传视频（mp4/mkv/mov 等）或音频（mp3/wav/m4a 等），同一个入口都收。**可以一次选多个文件**：它们会按同一套设置依次排队处理，不用一个一个提交
3. **已有字幕**（可选，强烈推荐）：手头已经有这个视频的原文字幕（.srt / .vtt）时打开这个开关并选上字幕文件，软件会**跳过语音识别直接翻译**。语音识别占整个流程约九成时间，实测 16.8 分钟的视频用本地 large-v3 识别要 140 秒，自带字幕只要 10 秒左右。你自己校对过的字幕想再翻成另一种语言，也用这个入口。注意：字幕的时间轴会原样保留，软件不做纠轴与反幻觉处理（那些是给机器识别结果纠错用的，人工字幕不该被"修"）。批量提交多个文件时不能带字幕（一份字幕对不上多个视频）
4. 选语音识别引擎（Groq / Groq Turbo / 本地 Whisper 各档）。**选完文件后，每个引擎后面会显示「预计耗时」**——各档之间差 5 倍以上，按你能接受的等待时间选：Groq 最快但需要代理，本地 large-v3 最准但最慢，本地 small 是离线场景的推荐档。预估按实测倍速 × 你的媒体时长算出，会区分本机有没有显卡；实际耗时受素材难度影响，仅供参考
5. 选目标语言，需要的话勾「双语字幕」
6. 可选「术语库」：下拉多选一个或多个术语库（默认「无」），选中的术语会注入本次翻译、保证译法统一；这里只做套用，不会往库里加新词
7. 可开「翻译风格」：选预设或自己写一句风格要求
8. 点「开始翻译」。进度：抽音频 → 语音识别 → 翻译 → 完成（自带字幕时前两步会跳过）
9. 完成后可以：编辑字幕、下载 SRT、下载译文 TXT、字幕烧录、AI 配音
10. 对结果不满意点「重试」：可以换识别引擎或语言重跑，不用重新上传文件

## 全能AI翻译（Agent 模式，实验功能）

上传后系统自动运转：识别内容领域 → 派多个领域专家并行抽术语 → 需要时联网核实译法 → 汇总仲裁打分 → 术语入库 → 带术语翻译全文。视频、音频、纯文本（txt/md/srt/vtt）都能处理。

**运行现场**：提交后右侧实时展示每一步——识别领域、专家抽词、联网查了什么（带可点开的网页链接）、汇总仲裁、术语入库、翻译。出问题的步骤会标黄色「降级」。

**模型配置（设置 → API 配置 → 大语言模型 → 全能AI翻译）**：可单独配「翻译模型」（负责最终逐行翻译），高级设置里可再分开配主 Agent（判断领域与仲裁）、子 Agent（抽词定译）、搜索引擎。全部不填就自动用默认的大语言模型服务。

**联网搜索（强烈建议配置）**：配了搜索引擎（Tavily / 博查 / Serper 三选一，填对应 API Key），专家遇到拿不准的专名会去搜官方译名，搜到权威来源的词直接入库启用。不配也能跑，但术语只能靠模型自身知识。Tavily 在 tavily.com 注册可拿免费额度；博查是国内服务可直连。

**新词存入哪个库**：任务表单的「新词存入」可以指定本次抽出的新术语存到哪个术语库。做系列内容（同一部剧、同一个主播、同一门课）时选同一个库，人名/招式/专业词就能全系列统一，越攒越准。不选就按内容领域自动归类到「【Agent】某某领域」。

**术语怎么入库（2026-08 改版）**：系统先问两件事——这个词值不值得记（音译/造词类、缩写专名、反复出现的复合术语才记，像 apartheid→种族隔离 这种有唯一标准译法的不占位置），以及这个译法有几分佐证。
- 有权威来源佐证，或多位专家、此前任务独立给出同一译法 → **直接入库并启用**
- 该记但暂时没佐证 → **入库为「备选」，先不生效**，在「术语库」页勾一下即可启用，说明栏会写清为什么是备选
- 不值得记的 → 只在本次翻译里保持一致，不占术语库

同一个词在两个不同任务里被独立抽出且译法一致，备选会自动转正。人工改过的词会被锁定，之后 AI 永远不会覆盖它。

**套用已有术语库**：任务表单里可下拉多选要套用的术语库（默认「无」），选中的术语与 Agent 本次抽出的术语合并注入翻译；同一个词两边都有时以你选的术语库为准。

**结果的文本操作**：任务完成后在列表操作栏可以——双语对照（弹窗逐行对照）、复制译文、网页查看译文（新标签页干净排版）、导出译文/导出对照（txt）、下载 SRT（音视频任务）、重译。

**我的专家**：可以自建最多 20 个领域专家（比如「机甲动画」「王者荣耀」）。填三样：什么内容归他管（帮系统判断）、这个领域的翻译惯例（怎么译）、搜索关键词（联网核实时带上的词，比如「高达wiki」）。建好后自动进入候选池，内容对得上就会被自动选中，不需要手动指定。

**LangSmith（可选，开发者功能）**：填 LangSmith Key 后，每次任务的完整执行过程（提示词全文、搜索结果、术语表）会上报到 LangSmith 网页端供分析。注意上报内容含完整台词，介意隐私就别开。

## 文本AI翻译

进「文本AI翻译」，粘贴或上传文本，选语言，直接翻译。适合快速翻译一段话、一篇文章，不涉及术语库。

## 文档AI翻译

整份文档上传、后台异步翻译、下载同格式译文，排版结构原样保留。

- 支持格式：PDF、Word（docx）、ePub 电子书、HTML、Markdown、TXT、JSON（只翻文案值，键名/结构不动）、字幕文件（srt/vtt/ass，时间轴不动）
- 用法：左侧栏「文本翻译」分组进「文档AI翻译」→ 拖入文档 → 选目标语言（可选翻译风格）→ 开始翻译。任务在后台跑，进度条实时刷新，完成后点「下载译文」
- 单文件上限 100MB；提交后可以关页面，稍后回来下载
- **PDF 有「保版式 / 快速」两档**（选中 PDF 后才出现这个选项）：
  - **保版式**（默认）：先做版面分析识别标题/正文/图表/公式，再按原栏宽与字号把译文重新流排回原位，原文文字被替换而非覆盖，图片、公式、页码、页边水印保持不变。最贴近原件，但慢——实测一份 72 段的简历要约 93 秒。首次使用需要一份约 340MB 的版面模型与字体资产（完整版安装包已内置，无需联网）
  - **快速**：内置引擎直接把译文回填到原文位置、放不下就缩小字号，排版从简。实测同一份 72 段 PDF 只要 13 秒，快约 7 倍。适合「只想快点看懂这份 PDF 讲什么」
  - 保版式所需的资产或组件缺失时会自动退回内置引擎，翻译不会中断；系统缺中文字体等极端情况会降级输出 Word。扫描版/纯图片 PDF 抽不出文字，两档都不支持
- 对照页说明：PDF/HTML 任务的「对照」默认是「版式对照」——左边原文件、右边译文文件并排渲染，就像双击打开文件的样子。走版式保持翻译的 PDF 由引擎整篇重排，不产生逐段对应关系，因此只提供版式对照；其他格式提供文本对照，可逐段检查（支持搜索、只看未翻译）
- docx 说明：整段翻译回填，段内局部加粗/变色等混合样式会统一为该段主样式
- 部分段落如显示「疑似未翻译」，是该批次翻译失败自动保留了原文（降级不丢内容），重新提交即可

## 划词翻译（浏览器扩展）

在任意网页上直接翻译。左侧栏进「划词翻译」页，按页面指引安装浏览器扩展（Chrome/Edge 加载已解压的扩展程序，只需一次），页面显示「已连接」即可用。翻译用的是设置里配好的翻译模型，本机软件需保持运行；连接有效期 90 天，过期重开「划词翻译」页自动续期。**软件关掉再打开后扩展会自动重连，已经打开的网页不用刷新就能接着用。**

用法（都在网页上操作）：
- **划词翻译**：选中文字 → 点旁边弹出的<b>悬浮球</b>，或右键选「狐译（划词翻译）」，或按 Alt+T
- **译文怎么显示**：在工具栏「狐」图标弹窗里三选一 —— **替换原文**（默认）/ **放在原文下方**（原文保留，译文另起一块）/ **弹窗展示**（网页一个字不改，译文在可拖动的小窗里看）
- **悬浮球**：默认开启，选中文字后自动出现；不想要可在工具栏「狐」图标弹窗里关掉
- **输入框翻译**：在任意输入框、文本框或富文本编辑器里打完字，**连按三下空格**，输入内容就地翻成目标语言（可在弹窗里关闭）
- **图片翻译**：网页图片上右键 → 「狐译（翻译这张图片）」，本地 OCR 引擎（随包内置、完全离线）识别图中文字和位置，再用你配置的翻译模型翻译，**译文直接写回图片上的原文位置**（自动匹配底色和字号）；结果浮层默认放在图片**旁边**而不是盖住图片，**按住标题栏可以拖到任意位置，位置会被记住**，浮层里提供「恢复原图 / 查看译文文本 / 看原文 / 复制译文 / 重置位置」。识别支持中英文，任何翻译模型都能用（包括 DeepSeek）
- **鼠标悬停翻译**：按 Alt+H 开启后，鼠标停在段落上约半秒自动翻译该段；再按 Alt+H 关闭。也可在「狐」图标弹窗开关
- **整页翻译**：按 Alt+P，或网页空白处右键 → 「狐译（翻译整个网页）」。**增量翻译**：翻过的文本会被标记，再次翻译只处理新增内容；网页后续动态加载出来的内容会自动追译，不会重复调用大模型
- **原文 / 译文切换**：按 Alt+R，或右键 → 「狐译（切换原文 / 译文）」，或在「狐」图标弹窗点「显示原文 / 显示译文 / 切换」。译文缓存在本地，**来回切换不再调用大模型、不消耗额度**
- **翻译历史**：划词、整页、图片、输入框的记录都进「划词翻译」页下方的翻译历史，可查看逐行对照、导出译文/对照、单条删除或一键清空；它们**不会**混进「文本 AI 翻译」的历史
- **目标语言**：「狐」图标弹窗里选，默认中文，对所有网页生效
- **快捷键**：默认 Alt+T 划词 / Alt+P 整页 / Alt+R 原文译文切换 / Alt+H 悬停，可在浏览器的扩展快捷键设置页修改（弹窗里有「修改快捷键」入口）

## 字幕编辑器

任务完成后点「编辑字幕」进入编辑器：逐行改译文、调时间轴、合并拆分行，改完可重新导出 SRT。字幕已存在本地数据库，随时能回来接着改。

## 字幕烧录

把字幕直接压进视频画面（硬字幕）。任务完成后点「字幕样式/烧录」，可调字体、字号、颜色、描边、位置，烧录完下载带字幕的视频文件。

## AI 配音（TTS）

任务完成后可为译文生成 AI 配音。默认用 Edge-TTS（免费、零配置、无需钥匙）。进配音页选音色、生成，完成后试听下载。个别行译文过长时会黄色提示（不影响成品）。配音失败不影响翻译成果，可以重试。

## 术语库管理

左侧栏「术语库」页统一管理所有术语：
- 按项目/来源筛选，搜索词条
- 修改译法、说明，启用/停用，批量移动、复制到其他项目，批量删除
- 「来源」列：自动=AI 抽取入库（KB 联网抽词与全能翻译产出都算）；人工=你自己录入或改过的（AI 不会覆盖）
- 「说明」列：这个词指什么、为什么采用该译法；有其他译法争议时也会写明
- 全能翻译产出的术语桶名字带【Agent】前缀，按领域自动归类
- 音频/视频翻译和全能翻译的任务表单里都可以下拉勾选术语库直接套用

## 翻译风格

各模式的任务表单里可开「翻译风格」：选预设标签或用一句话描述期望文风（比如「口语化、贴吧味」「正式书面语」）。术语表的优先级高于风格——术语对照永远严格执行。设置页「翻译偏好」可设默认风格、管理自定义风格预设。注意：传统机翻服务商（谷歌翻译/微软翻译/DeepL）不支持翻译风格。

## 翻译历史

「翻译历史」页汇总全部翻译记录：音视频任务、全能翻译、文档翻译、文本翻译，以及浏览器插件的划词/整页/图片/输入框翻译。可按类型和状态筛选；音视频任务可重试、下载、烧录、配音；文档可下载译文、看对照；文本/插件记录可查看逐行对照、导出译文/对照。工作台「最近项目」卡片也来自同一份历史。任务文件都在本地 `data\` 目录。

各模式页面里还有各自的独立历史，互不干扰：「文本 AI 翻译」页只列本页产生的文本/文本文件记录，浏览器插件产生的记录一律归「划词翻译」页下方的翻译历史（可单条删除或一键清空）。

## 常见问题（FAQ）

**翻译失败提示密钥错误**：检查 key 是否复制完整、账户是否有余额；Groq 报网络错误多半是代理没开。

**测试连接失败**：「设置 → API 配置 → 大语言模型」的「测试连接」会真实翻译一句话。失败时按提示检查 Base URL / Key / 模型；Gemini、GPT、Claude、Grok、谷歌翻译需要魔法上网；传统机翻（谷歌/微软/DeepL）没有模型列表，不用点「拉取模型」。

**提示「翻译模型未配置」**：去「设置 → API 配置 → 大语言模型」保存一条模型服务，并确认列表里它带「默认」标记且处于启用状态。

**视频翻译有漏句**：软件有多层防漏机制（轻声检测、缺口补翻、漏行补翻）。如果译文里个别行保留了原文，说明那几行翻译请求失败被自动兜底，任务会标「部分步骤降级」，点「重试」通常能补全。耳语/气声内容识别难度大，建议用 Groq 或本地 large-v3 模型。

**全能翻译不联网搜索**：先确认「设置 → API 配置 → 大语言模型 → 全能AI翻译 → 高级设置」配了搜索引擎和对应 API Key；另外是否联网由 AI 判断——内容里没有生僻专名时它认为不需要查证，属正常现象。

**术语全部自动处理，不用确认吗**：是的。可信度达标的术语自动入库，不达标的不会留在库里，无需逐条确认。想提高入库质量就配上联网搜索（有权威来源佐证的词更容易达标）；对个别词不满意直接在「术语库」页改，改过的词永久锁定。

**Groq 用不了**：国内网络需要代理才能访问 Groq（注册和使用都是）。不想用代理就选「本地 Whisper」，完全离线。

**处理长视频**：Groq 免费层一次只能处理约 2 小时内的音视频，更长的用本地 Whisper。

**翻译太慢怎么办**：先看时间花在哪一步。语音识别通常占九成——
① 手头有原文字幕就用「已有字幕」开关，直接跳过识别（实测 140 秒变 10 秒左右）；
② 没有字幕就按提交页显示的「预计耗时」换个引擎，Groq 最快（需代理），离线场景 small 比 large-v3 快约 3 倍；
③ 识别之外的环节：整本文档或两小时以上的长视频可以把模型服务的「并发请求数」调到 16；
④ 字幕烧录会自动使用显卡编码（检测不到显卡才用 CPU），实测比纯 CPU 快约一倍。

**烧录出来的视频画质/体积不对**：软件默认用显卡编码（NVIDIA/Intel/AMD 都支持），质量参数已调到与 CPU 编码相当。若你的显卡驱动有问题、或想让烧录不占显存（比如同时在跑本地语音识别），可以在启动前设环境变量 `BURN_VIDEO_ENCODER=libx264` 强制用 CPU 编码。

**数据备份/搬家**：全部数据在软件目录的 `data\` 文件夹里，拷走它就完成备份。换电脑把整个软件文件夹拷过去即可。

**安全性**：服务只监听本机，外网访问不了；密钥存在本机数据库。不要把 `data\` 文件夹发给别人。

**图片翻译报错或没反应**：图片翻译依赖本机的识别组件（完整包已内置，会自动启动；首次识别要加载模型，多等两三秒）。报「识别服务」相关错误时重启软件再试；识别支持中英文，手写体、艺术字、过小的文字可能识别不全。翻译模型用你配置的即可，DeepSeek 等纯文本模型完全没问题。

**扩展右键菜单不出现**：安装扩展前已打开的网页要刷新一次；浏览器内置页（chrome:// 开头）和扩展商店页不支持。

**端口被占用**：`start.bat 9090` 换端口。

## 隐私与数据

所有视频、音频、字幕、术语、密钥都存储在本机 `data\` 目录，软件本身不上传任何数据。会访问外网的只有你主动配置的服务：翻译模型接口、Groq 语音识别、联网搜索引擎、LangSmith 观测（默认全部可用本地方案或关闭）。
