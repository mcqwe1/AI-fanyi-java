    节点	    故障	                     降级产物
② 处理器链	无文本/乱码	提前失败，报错给用户（唯一允许终止点，防上游耗 token 后才发现源坏）
③ 场景推测	LLM 超时/输出异常	用 domain=auto 默认档案继续，术语质量降级但翻译继续
④ 单个子Agent	超时/工具超限/无结果	返回空，主 Agent 用其余结果继续
⑤ 置信度	某特征缺失	权重重新归一，不给缺项 0 分
⑦ 向量库	挂掉	退化为精确匹配（库仍可读可写，检索退化而非失效）
⑧ RAG检索	超时	裸翻（不带术语）+ degraded 标记 + 本次术语不入库
⑧ 单分片翻译	失败	重试 1 次 → 仍败回填原文+标记，整任务不崩
⑨ 烧录	ffmpeg 失败	交付未烧录的字幕文件，绝不整单失败
